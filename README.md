# Lindau

A 2027 Beethoven, Lindau, and fountain pen journey guide.

Website: https://pptnz.github.io/lindau/

Edit `index.html` to update the guide.

Leaflet 1.9.4 is bundled in `assets/leaflet/` with its license. Map tiles are served by OpenStreetMap and require an internet connection.

GitHub Pages publishes the repository root from the `main` branch. Push changes to `main` to update the website.
